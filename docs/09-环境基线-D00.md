## 2. 与现有 DSH Desktop 的隔离

- 现有 Desktop 使用 `desktop` profile，运行中（`DeepSeekRuntime.exe` 多进程）。
- **2026-11-15 修正**：只换 profile 不构成环境隔离——会话按 `$DSH_HOME\sessions\<工作目录>` 归档，工作区与附件也在 `$DSH_HOME`，跨 profile 共享。因此 NightDesk 使用**独立 HOME** `C:\Users\Names\.dsh-nightdesk`，profile 在其下的 `profiles\nightdesk`。
- 独立端口：`5593`（Desktop 当前 Web GUI 为动态端口，曾为 5592 / 4283）。
- 独立业务数据目录：`C:\Users\Names\.dsh-nightdesk\nightdesk-data`（插件自有 SQLite，**不读写 dsh 内部数据库**），由 `NIGHTDESK_DATA_DIR` 指定。
- 启动命令（两个环境变量都要设）：
  ```powershell
  $env:DSH_HOME = 'C:\Users\Names\.dsh-nightdesk'
  $env:NIGHTDESK_DATA_DIR = 'C:\Users\Names\.dsh-nightdesk\nightdesk-data'
  npx -y @deepseek-ai/dsh@0.2.2-rc.3 nightdesk --port 5593 --no-open
  ```
- 不修改 `desktop` profile 的业务配置，不覆盖默认 profile，不要求卸载 Desktop。

## 3. 插件实现形态（已核实源码）

- 纯 ESM JavaScript，无 TypeScript、无构建步骤、无第三方运行时依赖。
- 入口导出 `name` / `inject = ['tools']` / `apply(ctx)`。
- 工具通过 `ctx.tools.register(definition)` 注册普通对象；
  `parameters` 与 `output.schema` 使用**原生 JSON Schema**。
- 源码依据：`dsh-harness-src/packages/core/tools/src/index.ts:1071`（`register`）、
  `schema.ts:554`（`defineTool` 只是 DSL→JSON Schema 编译 + 参数校验）。
- **参数校验由插件自己完成**：registry 不校验 `parameters`。
- 禁止 `import '@deepseek-ai/*'`：npm 上 `@deepseek-ai/dsh-tools` 仅 `0.0.1-rc.1`，
  与 0.2.2-rc.3 不匹配，且 profile 内不可解析。
- 加载方式：profile `cordis.patch.yml` 增加
  `- insert: - id: nightdesk, name: '<插件 index.js 绝对路径>'`；
  或以 bundle 形式（`dsh.bundle.patch`）加入 profile `package.json`。

## 4. 数据库

- 使用 Node 内置 `node:sqlite`（`DatabaseSync`），已实测可用，无需 better-sqlite3。
- `PRAGMA journal_mode=WAL`、`foreign_keys=ON`、`busy_timeout=5000`。
- 版本表 `meta.schema_version = 1`，迁移用幂等 `CREATE TABLE IF NOT EXISTS`。

## 5. 时区与时间口径

- 存储一律 UTC RFC3339（`new Date().toISOString()`）。
- 业务展示与「今天」判定使用 `Asia/Shanghai`，通过 `Intl.DateTimeFormat` 计算，禁止手写时区偏移。
- 只有日期没有时刻时 `timeStatus` 不得伪造为 `resolved` + 具体 `dueAt`。

## 6. 本机 shell 注意事项

- PowerShell 为 5.1：无 `-Encoding utf8NoBOM`；写 UTF-8 无 BOM 文件用
  `[IO.File]::WriteAllText($p, $s, (New-Object System.Text.UTF8Encoding($false)))`。
- `npm` / `pnpm` 在 pwsh 中直接调用无输出，需 `cmd /c "npm ..."`。
- `Get-Content` 显示中文乱码是控制台编码问题，不代表文件损坏。
- `D:\DeepSeekRuntime` 目录对 shell 不可访问（Desktop 正在运行），不要依赖读取其 asar；
  插件契约以 `dsh-harness-src` 源码与 profile 内已安装包为准。
