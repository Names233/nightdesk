## 1. 主要决策

| 决策 | 当前选择 | 原因及复审条件 |
| --- | --- | --- |
| 产品主轴 | 一个人的消息、目标与Agent工作助理 | 同时解决漏事与多会话负担；若只剩提醒需回查覆盖 |
| 应用形态 | local-first模块化单体 | 降低前期运维；持续在线和资源瓶颈再调整 |
| 模型职责 | 理解/建议/有界规划/内容核对 | 状态权限仍由代码；模型更新不能改变边界 |
| worker | 0/1/N按需 | 多Agent有协调成本，实际评价再决定数量 |
| 接入顺序 | 分享+公开源、早期运行时探针 | 不以封闭渠道未证实接口作为成立前提 |
| 手机提醒 | P1必过 | 网页待办不解决关闭页面后的漏事 |
| 成果 | 不可变内容+再验证Manifest | 保留沿用与版本一致性 |
| 动作 | 明确授权+ledger+对账 | 外部副作用不能保证精确一次 |

后续变更新增决策记录：背景、备选、理由、证据、迁移影响与回退，不悄悄覆盖原约束。

## 4. 证据层次

文档阅读→能力探针→端到端测试→真实使用评价，四者分别记录。文档只能支持方向；探针固定版本与身份范围；端到端包含设备或宿主最终表现；使用评价才回答是否有用。

当前只有设计与资料阅读，可说拟支持、推荐架构，不能说已稳定接入、不会漏事、已节省多少时间。所有样例明确合成，不伪造访谈或测评。

## 5. 配对评估协议

A是原工作方式，B是拾光哨；任务配对尽量保持难度、输入、权限、工具和质量要求，记录熟练度、顺序和环境。C仅在可比时加入强单Agent，不可比则单列。

第i对主动人工节时率：s_i = (t_A,i - t_B,i) / t_A,i，要求t_A,i>0。主动时间含阅读、切换、选择、核对与恢复，不含纯等待；等待另报。报告每对差值、s_i中位数与范围，不混用两组中位数降幅。

失败、弃用、回到原流程和额外修复保留；未完成单列质量失败/未完成，不用删除样本制造节时率。首次设置与日常使用成本分开，调参和评价样本分开，顺序交叉或随机化。

关键事项召回分母为声明覆盖范围内金标，另报总来源覆盖；未接入群不掩盖。日期报告正确、未知和错误确定化；通知报告提交到设备各段证据；质量看需求、事实、可追溯与可用性。

成本包括模型、外部通道、运行与人工核对；未知账单标估算。小样本逐项报告，不把无显著差异当质量等效，不先承诺固定30%效果。
