# D03 实现简报：宿主会话只读探针

本简报是自包含实现契约。实现者只改下文列出的文件。

## 背景与边界

- NightDesk 需要「看住正在进行的会话」：知道有哪些会话、各自有多少轮、最后一次读取到哪个位置、上次读取时间。它**不假装知道会话是否在运行、是否等待审批**——宿主没有通过这条只读面暴露该状态，因此必须输出 `runState: 'unknown'` 并写明原因。
- 只读原则：D03 只允许调用宿主只读服务 `sessionQuery`，绝不创建/重命名/恢复/取消任何会话，绝不使用 `sessionController` 的写方法（`prompt`/`cancel`/`rename`/`fork`/`create`/`selectModel` 等）。
- 插件必须保持软依赖：`src/index.js` 的 `inject` 仍为 `['tools']`；`sessionQuery` 在运行时用 `ctx.get('sessionQuery')` 获取。若无该服务（headless/精简组装），工具返回 `{ available: false, reason: 'sessionQuery-unavailable' }`，不抛错、不影响其它工具。

## 已核验的宿主 API（实现时直接按此调用）

- `ctx.get('sessionQuery')` 返回 `SessionQueryService`，可用只读方法：
  - `listSessions(signal?)` → `SessionRecord[]`（newest-first），每项含 `header`、`live`、`persisted`、`formatStatus`。
  - `readSurface(id, options?)` → `{ session, inheritedEventCount, capturedThroughSeq, events }`。
  - `readSession(id, options?)` → 完整原始日志快照。
  - `observeSession(id, options)` → observation（需 `using` 释放）；本任务不需要它，若使用必须正确释放。
- `SessionEvent` 形状（`packages/core/session/src/types.ts:494`）：`{ type: string, seq: number, time: number /* 毫秒 */, data: unknown }`。
- `SessionHeader`（同文件 `:95`）字段：`version`、`id`、`createdAt`（毫秒）、`cwd?`、`parentSession?`、`isSeeded`、`origin?`、`delegationDepth?`、`agentPreset?`。**没有运行状态字段**。
- 错误码示例：`SESSION_QUERY_SESSION_NOT_FOUND` 等；实现时按 `error.code` 判断，不匹配字符串消息。

## 目标

在插件内提供「会话观察名单」：用户把某个 dsh 会话加入名单后，NightDesk 可以随时刷新并给出一份带读取时间与范围的只读快照；这份快照是 D07 工作汇总的输入之一。

## 验收标准

1. `node --test packages/dsh-nightdesk/test` 全绿，现有测试数量不减少；新增测试不少于 10 项。
2. `schema_version=4` 新增：
   ```sql
   CREATE TABLE IF NOT EXISTS watched_sessions (
     id TEXT PRIMARY KEY, owner_id TEXT NOT NULL, session_id TEXT NOT NULL,
     label TEXT, added_at TEXT NOT NULL, last_read_at TEXT, last_seq INTEGER,
     last_event_at TEXT, last_event_type TEXT,
     status TEXT, error TEXT, created_at TEXT NOT NULL, updated_at TEXT NOT NULL);
   CREATE UNIQUE INDEX IF NOT EXISTS watched_sessions_unique
     ON watched_sessions(owner_id, session_id);
   ```
3. 新增 `src/sessions-probe.js`，导出 `createSessionProbe({ getSessionQuery, now, store })` → `{ watch, unwatch, list, refresh }`：
   - `watch({ ownerId, sessionId, label })`：写名单，返回记录；重复 watch 同一 session 为幂等更新 label，不报错。
   - `unwatch({ ownerId, sessionId })`：删除，返回 `{ removed: boolean }`。
   - `list({ ownerId })`：返回名单记录（不访问宿主）。
   - `refresh({ ownerId, sessionIds? })`：对每个观察项读取一次宿主快照，更新 `last_read_at`（RFC3339）、`last_seq`、`last_event_at`、`last_event_type`、`status`、`error`，返回逐项结果：
     ```json
     { "sessionId": "...", "label": "...", "found": true, "live": true, "persisted": true,
       "capturedThroughSeq": 412, "eventCount": 413, "inheritedEventCount": 0,
       "lastEvent": { "type": "assistant/message", "seq": 412, "time": "2026-11-14T14:02:11Z" },
       "readAt": "2026-11-14T14:10:00Z", "runState": "unknown",
       "runStateReason": "host read seam does not expose run state",
       "status": "read_ok", "error": null }
     ```
   - `refresh` 必须容错：单个 session 读失败（不存在 / 抛错）只标记该项 `status='read_failed'|'not_found'` 并继续其余项，整体不抛错。
   - 不得调用任何写方法；代码里搜索不到 `prompt(`、`cancel(`、`rename(`、`fork(`、`create(` 对 sessionController 的调用。
4. 新增工具（沿用现有 `definition()` 风格）：
   - `nightdesk_session_watch`：`{ sessionId: string, label?: string }`。
   - `nightdesk_session_unwatch`：`{ sessionId: string }`。
   - `nightdesk_sessions`：`{ refresh?: boolean }`（默认 `false`）；`true` 时先刷新再返回；服务不可用时返回 `{ available: false, reason }`。
5. 所有时间用 RFC3339 UTC（`new Date(ms).toISOString()`），`now` 可注入以便测试固定时间。
6. 纯 ESM JavaScript、零第三方依赖、不 import 任何 `@deepseek-ai/*`；不做 commit/push。
