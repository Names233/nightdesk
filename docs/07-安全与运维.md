## 1. 信任边界

保护私人消息、课程、会话、附件、凭据、授权与动作。分享一条只处理这条，不自动取得整个群或账号权限。单用户也在存储和查询显式检查 ownerId。

本地默认限制监听并认证；远程使用 TLS、明确可信代理和登录保护。本机地址不等于浏览器来源可信。通用网页采集和用户配置的受控本地运行时是不同网络能力。

## 2. 主要威胁与控制

| 威胁 | 控制与失败行为 |
| --- | --- |
| 外部内容提示注入 | 不可信资料结构化隔离；工具和授权由内核检查 |
| OCR/日期误判 | 证据回看、候选和人工确认；不错误确定化 |
| 恶意 URL / SSRF | 协议、端口、DNS、实际连接、重定向校验 |
| HTML/附件攻击 | 清洗、禁宏、大小/层数/超时限制、受限解析 |
| 跨对象和 CSRF | 认证、ownerId、Origin、CSRF保护、事件流握手 |
| 批准重放/替换参数 | 一次action、规范哈希、版本epoch、有效期 |
| worker迟到 | v0.3 校验身份、goalVersion、attempt、CAS 与不可变 Artifact；通用执行扩展再加 lease、fencing |

## 3. 输入与网络

网页、截图、附件和其他 Agent 回复均不可信。模型检测注入只是辅助，不作为唯一防线；资料中要求忽略规则、发密钥或执行命令不获得工具权限。

抓取器拒绝本地文件协议、回环、私网、链路本地、云元数据和其他受限地址。每次 DNS、实际连接与重定向复验，防 DNS 重绑定；限制体积、耗时、重定向和解压层数。代理环境也要验证实际路由。

为 dsh/Codex 配置受控本地连接不能顺带给任意网页放开内网。附件不得直接执行宏、脚本或任意命令。展示清洗后的内容，默认不加载远程追踪资源。

## 4. 认证、凭据和模型

写请求核验身份、Origin 和适用 CSRF 防护，Cookie SameSite 不是唯一措施。WebSocket、推送订阅和回调同样检查来源、对象和关联标识。

secretRef 指向 OS 凭据存储或受控本地容器，不放明文于业务字段、提示词、日志和示例。轮换后更新引用版本，失效连接报告健康异常。

用户知道哪些信息会离开设备以及发送给哪个服务。必要脱敏和最小化先做；不能满足要求则只处理摘要、选本地模型或关闭相关功能。本地模型不免除工具隔离。

常规日志不存完整提示词。临时调试捕获有范围、保留期和清理，不把故障排查变成永久私人资料库。

## 5. 执行保护

v0.3 本地草稿在变更或停止后不再启动新工作，并拒绝旧 attempt 提交。外部动作开放时，policyEpoch 和停止状态必须在派发前复验，不仅在点批准时检查；停止撤销 pending、granted 与未取得派发资格令牌，已发出动作可能继续，界面显示而非保证撤回。

未知副作用不进入通用自动重试。查稳定请求标识、回执或目标状态，证据不足待人工。目标变更、租约失效和备份恢复均不能清除账本。

原生运行时要求本人处理的检查点继续保留，远程汇总层不能伪装本人、降低权限策略或自动同意。

## 6. 运维与可观测性

启动、退出、休眠和网络条件有明确说明。恢复不把启动时间当 lastSuccess；补采显示范围。错误按认证、限流、结构、网络、解析和权限分类，退避与重试有上限。

指标包括来源新鲜度、缺口、Outbox积压、截止调度延迟、未送达提醒、过期租约、未知动作、模型费用和资源。健康页可定位具体受影响事项。

提醒通道故障不能只向同一故障通道发送告警；应用内显著显示，备用通道由用户另行配置。不能用后台日志声称用户已获知。

## 7. 备份、恢复和保留

业务存储按实际宿主能力选择一致性备份；采用 SQLite 时使用 Online Backup API 或验证过的一致性机制，WAL 运行时不只拷主文件。数据库、对象和共同清单备份加密或按敏感级保护，不入公开仓库。

恢复在隔离环境检查完整性、外键、哈希、对象引用、批准消费状态和 Outbox。旧备份可能丢掉后来已发出的记录，无法对齐时保守隔离动作，先人工对账，不立即恢复自动派发。

证据不可变不等于不能依法删除。用户删除或保留期到达时清理原文、派生副本和索引，留下最小脱敏元审计。明确备份清理延迟、必要账本保留和恢复后删除重放，避免删除内容复活。

导出包含目标、事项、出处、个人规则和成果，凭据默认不导出。删除前说明范围，验证实际清理而非只隐藏界面。

## 8. 阶段基线与事故

P0：固定宿主与权限边界，分别验证转发、手机和 dsh 只读探针。P1：身份归属、输入清洗、公开链接的 SSRF 防护、secret 隔离、Outbox、一致性备份和真实手机测试。P2：选定会话白名单、运行时最小权限、事件范围和原生审批。P3：本地草稿的身份与版本校验、停止、旧 attempt 拒绝和成果核对。外部动作的授权绑定、消费、停止竞争、迟到结果和未知对账在实际开放对应动作前验收，不作为 v0.3 本地草稿的提前宣称。

事故时停相关派发、保全最小证据、界定影响、恢复数据或轮换凭据，说明实际后果并复测。没有证据就说明未知，不把状态改成功以整理界面。

## 9. DSH 宿主信任边界

profile、plugin、session、event 和 approval 按 dsh 版本与能力声明隔离。NightDesk 不直接写 dsh 内部数据库，不把外部转发内容中的指令提升为插件权限。用户主动转发只授权处理这条材料，不扩展到群、联系人或平台账号全量权限；宿主审批和安全策略继续保留。
