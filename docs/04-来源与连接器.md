## 1. 渠道矩阵

| 来源 | 起步接法 | 尚未证明的能力 |
| --- | --- | --- |
| 学校、学院官网 | 逐站公开列表、正文与附件 | 全历史、所有栏目、结构稳定 |
| 校团委、院团委、教务 | 与官网一样逐路径配置 | 通知完整性、修订关系自动可靠 |
| 学习通 | 首版用户主动转发；独立研究 Web 优先只读接入 | 可授权学生 API、作业完整列表、提交回执 |
| 雨课堂 | 首版用户主动转发；独立研究 Web 优先只读接入 | 可用个人接口、课堂任务与提交状态 |
| 微信群与私聊 | 主动复制、截图、文件分享 | 全量个人历史读取、持续后台采集 |
| QQ 群与私聊 | 用户分享；官方机器人作为独立试验 | 任意已有私人群历史读取 |
| dsh | 固定版本能力探针，再读取事件 | 稳定 SDK、现有会话控制、审批桥接 |
| Codex | 固定 app-server 版本探针 | 已开 CLI/App 会话可接管 |

来源配置展示接法、覆盖范围和最后验证版本。没有接入的渠道继续依赖用户查看原应用，不能宣传从此不用看群。

## 2. 公开网站

逐站核对公开访问、使用条款、robots 和频率。robots 允许不等于全部使用授权。遇访问拒绝、验证码或账号要求时停下该路径，不自动寻找绕过方式。

列表分页、置顶、详情、附件、图片日期、编辑和撤回都影响覆盖。只读首页不能声称完整；附件解析失败也要保留原入口和缺口。

规范 URL、内容哈希用于精确去重；标题和语义相似只产生合并候选。转载保留多份观察，冲突不以最新抓取覆盖。明确更正公告建立修订关系；不明确则待核对。

优先使用可验证的条件请求和有限时间窗口重读；指数退避、并发限制与来源预算可调。结构变化触发报警和人工修复，不静默输出空结果。

## 3. 用户主动分享

支持粘贴、上传截图或文件、分享链接；系统保留提供方式、用户描述的来源、原始时间和观察时间。分享一条不代表授权整个账号或联系人列表。

剪贴板读取只在用户明确触发时进行。截图 OCR 有误，关键日期与对象必须可回看原图。隐私内容上传模型前明确数据范围，并可选择仅规则或本地处理。

对已导入内容建立持久跟进，不要求用户每天重新录入；但未分享的新变化不能假装已自动知道。

## 4. 微信和 QQ

本轮没有核验微信个人账号全量读取能力。QQ 官方机器人支持一定群、频道和单聊场景，但主体认证、服务范围、事件和历史权限有条件，不能据此声称读取用户所有群。

机器人只作为用户主动发送给助理的私聊入口，不入群、不监听原群。任何试验记录实际可接收事件、授权身份、附件范围和数据使用范围；群管理条件不是首版探针前提。

不把未经验证的私人协议、客户端解密或无差别监控作为默认工程基础。未来本地辅助能力另做平台规则、用户授权、稳定性和第三方隐私评估。

## 5. 学习通与雨课堂

目前仅核验官方产品页，未验证学生 API 或登录自动读取许可。首版主线采用用户主动转发并人工核对；独立研究线按本节第 9 条验证 Web 优先的自动只读路径，不能将官网入口存在等同于有可用 API。

没有回执不写未提交；没有余量不写剩几个名额；没有完整课程范围不写所有作业已同步。平台证据与人工标注分开。

后续可研究用户授权、本地正常登录的只读浏览器路径，先验证条款与数据范围，不绕验证码，不获取他人身份，不做代签到考试。浏览器可操作不证明平台允许自动化。

## 6. 能力探针

| 字段 | 需要证明 | 失败时 |
| --- | --- | --- |
| identity / ownership | 凭据可见对象与可控任务归属 | 限范围或只读 |
| eventId / revision | 稳定去重和更新识别 | 重读并显式待合并 |
| cursor / history | 续读、分页和缺口 | 标记覆盖不完整 |
| attachments | 可取、可解析、限制 | 显示附件未覆盖 |
| receipt / cancel | 接受、完成、取消语义 | 保留未知或只停本地 |
| approval | 原生请求、身份和一次性响应 | 回宿主，不提供远程批准 |

每次探针记录日期、版本或 commit、授权身份范围、输入条件、成功与失败样例。不把阅读官方文档计为探针通过。

## 7. 手机通知

Web Push 需要 Service Worker、用户订阅和兼容环境。推送 endpoint 属于敏感能力 URL，不公开。网络、电池、权限和订阅失效均影响效果。

P0 先证明一个真实手机通道可用；P1 必须完成端到端验收：设备与系统、权限、页面关闭、锁屏、重启、断网、提交时间、实际观察和打开分别留记录。服务返回成功不能代替锁屏观察。QQ 是首个候选手机通道，微信单独探针，v0.1 不要求两者同时完成。

**调度到期、投递会话、渠道接受、手机显示、用户打开、事项完成是不同状态。** 已确认提醒必须有确定性发送路径，模型故障或额度耗尽时仍可运行；模型故障测试必须验证真实手机发送路径，应用内待办只能记录降级，不能替代手机验收。改期或完成后旧提醒失效，发送结果未知时先对账。

Web Push 不适用则切换已验证的邮件等通道，同样记录时延与限制。备用通道由用户选择并授权，不自动把私人材料发给其他服务。

## 8. 降档和健康

自动读取 → 用户触发读取 → 主动分享 → 人工登记。降档只改变证据获得方式，不放宽权限或日期准确性。

来源保留 lastAttempt、lastSuccess、cursor、gap、lastError、coverage；通知有独立健康。单来源失败不清空全局清单，旧事项标注新鲜度，用户可继续处理已确认内容。

## 9. 当前连接器路线

QQ 是首个候选私聊渠道，微信只有独立探针通过后才加入；v0.1 不要求两个渠道同时完成，也不要求机器人入群或监听原群。dsh 渠道插件只接收用户主动转发的事件，NightDesk 保存来源、原始证据和附件引用后再解析，不因此获得群或账号全量权限。

输入顺序为**文字 → 单张截图 → 公开链接**。附件先保存原件并标明解析缺口，复杂 Office、音频和视频后置。公开网页、未来学习平台连接器沿用相同的 Observation 与事项边界，不能绕过 dsh 宿主权限。

学习通与雨课堂自动只读接入保留为独立研究线：每个平台先投入 **1—2 个有效人日**，Web 优先验证正常登录后的课程、作业、考试、公告和截止字段，以及分页、登录失效与限流；Web 证据不足时再以合法取得的官方 APK 做静态补证，记录版本、签名和哈希。只有稳定后端且确有独立 CLI 需求时才考虑 CLI-Anything。静态字符串不等于接口调用成功，不做自动签到、答题或代交。截至当前公开资料未发现普通学生 API，不能宣称已接入。
